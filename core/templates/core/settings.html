Path translation

Rewrites an *arr filesystem path into the path Plex reports. Container mounts differ between apps — Radarr may see /data/media/movies where Plex sees /movies. A missing or wrong mapping is one of the most common causes of "it imported but never showed up", so Sleutharr reports it as its own diagnosis rather than claiming the file is missing.
